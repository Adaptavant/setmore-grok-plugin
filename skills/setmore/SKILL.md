# Setmore

Guidance for using the Setmore MCP tools in Grok Build.

- Look up staff, services, customers, and availability with the Setmore tools before acting — don't guess ids, durations, or prices.
- Check availability with the scheduling tools before booking an appointment.
- Confirm with the user before cancelling, rescheduling, or deleting anything.
- Never show internal ids, timestamps, or raw field names to the user — use names and friendly dates/times instead.
